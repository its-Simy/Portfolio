# Personal Portfolio Website

Welcome to my personal portfolio website! This project serves as a digital reflection of who I am beyond just my professional capabilities as a programmer. It highlights my personality, interests, significant projects I've worked on, and provides insight into the person behind the code.

## Project Overview

In developing this portfolio, my goal was to create a space that authentically represents myself both professionally and personally. It showcases my:
- Background and personal interests
- Technical skills and programming projects
- Passion for creating engaging, interactive user experiences

I chose the following technologies due to their performance, flexibility, and ease of creating dynamic, responsive interfaces:

- **Next.js**: A React framework that enables optimized performance, seamless navigation, and server-side rendering, making the website fast and SEO-friendly.
- **Tailwind CSS**: Provides a utility-first approach to CSS, allowing rapid styling and responsive design that ensures a polished, modern aesthetic.
- **Framer Motion**: Facilitates sophisticated and smooth animations that enhance user interaction and overall experience on the site.

## Getting Started

Follow these instructions to run the project locally on your machine:

### Prerequisites

Ensure you have the following installed:

- [Node.js](https://nodejs.org/en/) (version 16.x or newer recommended)
- [Git](https://git-scm.com/downloads)

### Installation

1. Clone the repository:

```bash
git clone <repository-url>
cd <repository-name>
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

4. Open your browser and navigate to:

```
http://localhost:3000
```
